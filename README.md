# Auto Typer Plugin for Obsidian

> **⚠️ STATUS: EXPERIMENTAL VERSION**
>
> This plugin is under active development and is provided **for testing and demonstration purposes only**.
> Use with caution in production vaults.

## 🎯 Purpose

**Auto Typer** is an Obsidian plugin that simulates automatic typing character by character. It was primarily developed for:

- 🎬 **Creating explanatory videos** and tutorials
- 📽️ **Live presentations** where typing demonstration is needed
- 🧪 **Interface testing** and workflow validation
- 📝 **Obsidian feature demonstrations**

## ✨ Features

- ⌨️ **Automatic typing** from clipboard content
- ⚡ **Adjustable speed** (10ms to 500ms between characters)
- 🔄 **Auto-start** when new text is copied
- ⏹️ **Stop command** to halt typing at any moment
- 📋 **Intuitive settings interface**

## 🚀 How to Use

### Basic Usage

1. **Copy** the text you want to "type"
2. **Position the cursor** in the Obsidian editor
3. **Activate the command** "Type clipboard content" (via command palette or keyboard shortcut)
4. **Watch** the plugin typing character by character
5. **Stop anytime** with the "Stop typing" command

## ⚙️ Settings

| Option           | Description                                         |
| ---------------- | --------------------------------------------------- |
| **Typing speed** | Interval between characters (10-500ms)              |
| **Auto-start**   | Automatically start typing when copying new content |
